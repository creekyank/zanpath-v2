你的问题其实分成 两个部分，我分别给你结论 + 建议修改。

一、CTA 文本要不要 AI 生成？

先说结论：

最好让 AI 生成 CTA text，但不要放在文章 Markdown 里。

原因：

你现在系统结构是：

article_en.txt   → Markdown
seo_en.json      → SEO数据

如果把 CTA 写在文章里：

## Conclusion

...

CTA: Discover your Bazi life path with AI analysis on Zanpath.

会产生问题：
   •   mdToBlocks 解析不到
   •   CTA位置不可控
   •   SEO污染

所以正确做法：

把 CTA text 放进 seo_en.json。

例如：

{
 "metaTitle":"",
 "metaDescription":"",
 "primaryKeyword":"",
 "summary":"",
 "featuredSnippetAnswer":"",
 "ctaText":"Discover what your Bazi chart reveals about your life path with AI analysis on Zanpath.",
 "faq":[]
}

然后页面逻辑：

const ctaText =
  seo.ctaText || getDefaultCtaText(locale, module);

这样：
   •   AI写了 → 用AI
   •   AI忘写 → 自动fallback

这是内容工厂最稳定架构。

二、SEO JSON Prompt 需要增加 CTA

你的 SEO Prompt 只需要加一个字段：

"ctaText":""

更新后的 JSON 结构：

{
  "metaTitle": "",
  "metaDescription": "",
  "primaryKeyword": "",
  "secondaryKeywords": [],
  "longTailKeywords": [],
  "semanticKeywords": [],
  "keywords": [],
  "summary": "",
  "featuredSnippetAnswer": "",
  "ctaText": "",
  "faq": [
    {
      "question": "",
      "answer": ""
    }
  ]
}

并在 Prompt 里加一句：

ctaText: a short call-to-action encouraging users to explore AI analysis on Zanpath (max 20 words).

例如 AI 会生成：

"ctaText": "Explore what your Bazi chart reveals about your personality with an AI-powered analysis on Zanpath."
