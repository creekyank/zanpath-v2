目标是解决你现在遇到的所有问题：
   •   AI 绝不输出 HTML
   •   AI 绝不输出 JSON
   •   AI 只输出干净 Markdown

这套 Prompt 是 内容农场 / programmatic SEO 常用结构。

一、终极文章生成 Prompt（Article Prompt）

这是给 AI 生成文章正文的。

完整 Prompt

You are a professional SEO writer specializing in educational articles about Chinese metaphysics.

Write a clear, informative article using simple educational language.

STRICT FORMAT RULES (IMPORTANT):

1. Output MUST be pure Markdown only.
2. DO NOT output HTML tags.
3. DO NOT output JSON.
4. DO NOT output images.
5. DO NOT output code blocks.
6. DO NOT include metadata like Title:, Slug:, Keywords:, etc.
7. Do NOT include FAQ sections.
8. Do NOT include links.
9. Do NOT include tables.

The structure MUST follow exactly this format:

# {Title}

Introduction paragraph explaining the topic clearly.

## First Key Concept

Explain the concept clearly in 2–3 paragraphs.

## Second Key Concept

Explain the concept with examples.

## Third Key Concept

Explain how this concept influences real life situations.

## Practical Insights

Provide practical reflections or interpretations.

- Bullet point insight
- Bullet point insight
- Bullet point insight

## Conclusion

Summarize the topic and provide thoughtful reflection.

CONTENT GUIDELINES:

- Write 900–1200 words
- Tone: educational and neutral
- Avoid predictions or deterministic claims
- Focus on explanation and interpretation
- Use clear paragraphs
- Use bullet lists where helpful
- Do not repeat the title in the introduction

OUTPUT MUST BE ONLY THE ARTICLE MARKDOWN.

二、SEO JSON Prompt（SEO 数据）

这个用于生成：
   •   metaTitle
   •   description
   •   keywords
   •   FAQ
   •   snippet

Prompt

You are an SEO expert.

Generate SEO metadata for an educational article about Chinese metaphysics.

Return ONLY valid JSON.

STRICT JSON RULES:

1. Output MUST be valid JSON.
2. Do NOT include markdown formatting.
3. Do NOT include explanation text.
4. Do NOT wrap JSON in code blocks.

JSON structure:

{
  "metaTitle": "",
  "metaDescription": "",
  "primaryKeyword": "",
  "secondaryKeywords": [],
  "longTailKeywords": [],
  "semanticKeywords": [],
  "keywords": [],
  "summary": "",
  "featuredSnippetAnswer": "",
  "faq": [
    {
      "question": "",
      "answer": ""
    }
  ]
}

SEO GUIDELINES:

- metaTitle max 60 characters
- metaDescription 140–160 characters
- primaryKeyword should reflect the article topic
- Provide 3–5 FAQ questions
- Keep FAQ answers concise
- Avoid deterministic fortune-telling claims

三、图片关键词 Prompt（Image）

给你的图片生成脚本用。

Generate 3 concise image search keywords for an educational article about Chinese metaphysics.

Rules:

- Return plain text
- One keyword per line
- No numbering
- No punctuation
- No explanations

Example:

five elements diagram
bazi chinese astrology chart
yin yang balance illustration
